# Match Point

月ごとのマッチングアプリ活動を、感情ではなく傾向で振り返るためのスマホ向けWebアプリです。

## 機能

- 月初いいね数 / 追加いいね / 消費いいね
- マッチ数 / 会話継続数 / 通話数 / 会った人数 / 2回目人数
- マッチ率、会話継続率、デート到達率、2回目率の自動計算
- 会った人を匿名名で振り返り
- 「自分はまた会いたいか」と「相手の反応」を分離して記録
- 月ごとの会えた人数・マッチ率の推移
- 端末内 `localStorage` 保存

## GitHub Pagesで公開

Repository の **Settings → Pages** を開き、`Deploy from a branch` を選択。Branch を `main`、Folder を `/ (root)` にして Save すると公開できます。

データはブラウザ端末内に保存されるため、GitHub上には入力した恋活データは保存されません。別端末・別ブラウザには自動同期されません。
